# imsi1

Temporary public workspace for the OutRun 2006 Ferrari cockpit geometry rework.

## Purpose
- Store editable Blender checkpoints, modeling scripts, QA notes, manifests and comparison renders for slots A/C.
- No encryption is required for modeling artifacts in this temporary repository.
- Raw original game archives/PMT packages and private reference-photo collections should remain outside this repository.
- The repository is intended to be deleted after the Ferrari modeling project is completed and final deliverables are transferred.

## Active automation
- Slot A: Daytona365
- Slot C: F50
- SSOT files: `docs/automation/FERRARI16_GEOMETRY_QUEUE.json`, `docs/automation/FERRARI16_BREADTH_FIRST_STRATEGY.md`
